# 🎟️ CupomGanho - App de Cupons e Cashback

Um aplicativo revolucionário para encontrar cupons, descontos e ganhar cashback em suas compras no Brasil! 💰

## ✨ Funcionalidades

✅ **🎟️ Busca de Cupons** - Encontre descontos perto de você  
✅ **💰 Cashback** - Ganhe dinheiro de volta em suas compras  
✅ **🏪 Lojas Locais** - Descubra ofertas em lojas próximas  
✅ **👤 Perfil** - Gerencie sua conta e histórico  
✅ **🎁 Referência** - Convide amigos e ganhe bônus  
✅ **📊 Histórico** - Acompanhe seu cashback e economias

## 🛠️ Tecnologias

- **React Native** - Framework multiplataforma
- **TypeScript** - Tipagem segura
- **React Navigation** - Navegação entre telas
- **Material Community Icons** - Ícones profissionais
- **Axios** - Requisições HTTP
- **AsyncStorage** - Armazenamento local

## 📋 Pré-requisitos

- Node.js (v14+)
- npm ou yarn
- React Native CLI
- Android Studio (para Android)
- Xcode (para iOS)
